# FBPly Mobile Assets

Generated Android and Play Store source images live here.

- `android/icon.png`: 1024px launcher source.
- `android/splash.png`: 2732px splash source.
- `play-store/icon-512.png`: Play Console app icon candidate.
- `play-store/feature-graphic.png`: Play Console feature graphic candidate.

Run `powershell -ExecutionPolicy Bypass -File tools/generate-android-assets.ps1` after changing `public/fbply-logo.png`.
